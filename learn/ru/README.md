# Учебник: ролики с агентом, без блогерства

Это учебник для человека. Рецепты в [recipes/](../../recipes/README.md) написаны для агента: коротко, с
параметрами и проверкой. Здесь объясняется, почему так: на живых роликах из [examples/](../../examples/README.md),
с цифрами как историей и с ошибками, на которых мы учились. В конце каждого раздела ссылка на рецепт, который
можно отдать агенту.

Каждая глава открывается настоящим опубликованным роликом, разбирает приёмы по схеме «проблема, как увидели, что
делаем, где ломается» и заканчивается упражнением на 15–30 минут и списком «чего не делать».

Не знаешь, с чего начать: [маршрут обучения](ROADMAP.md) раскладывает учебник на четыре ступени, от первого вечера
до первого месяца, с признаком «готово» на каждой. Если читать подряд, начни с главы 00: она проводит через весь
путь за один вечер. Глава 00а объясняет, как всё это устроено под капотом. Остальные главы читай по мере того, как
упираешься в этап.

Весь учебник одним PDF лежит в [последнем релизе](https://github.com/ilyautov/not-a-blogger/releases/latest).
Собрать его самому: `python3 scripts/build_textbook_pdf.py` (нужны зависимости из
[tools/carousels/requirements.txt](../../tools/carousels/requirements.txt) и poppler: `brew install poppler`).

## Как устроена глава

- **Пример.** Постер и короткий рассказ о ролике: что в нём было и чем кончилось.
- **Приёмы.** Каждый подраздел: проблема на примере, цифра, по которой мы её увидели, что делаем, где приём
  ломается. Последней строкой ссылка «Рецепт для агента».
- **Упражнение.** Что сделать самому за 15–30 минут, без установки моделей, где это возможно.
- **Чего не делать.** Короткий список граблей главы.
