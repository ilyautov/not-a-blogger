# Script and hook

Use a not-a-blogger checkout and read [AGENTS.md](../../../AGENTS.md). Input: the person's material/topic,
language, audience and intended outcome; reuse an existing brief and approved lines.

Start from the [material](../../../prompts/script/scenario-from-material.md) and
[viewer knowledge](../../../prompts/script/viewer-knowledge-table.md). Choose a relevant
[hook](../../../prompts/script/hook-first-second.md) and a payoff that answers it. Match the form to the material:
an explanation, experiment and sketch need different structures. Keep source links with factual claims;
use [fact-check](../../../prompts/script/fact-check.md) and [meaning-check](../../../prompts/script/meaning-check.md)
when applicable. Don't invent source evidence to rescue a script.

For a hook-only request, change the opening and check its connection to the existing ending. Preserve the rest of
the approved text. For a full script, supply exact spoken lines and visible action per line, with a duration estimate.
Use [text cleanup](../../../recipes/text/text-humanize-script-before-tts.md) before TTS, preserving names and numbers.

Output: proposed lines or a scoped diff, source uncertainties and approval state, recorded in the existing script/brief.
Show changed spoken text before production. Do not generate voice, artwork, scenes or an MP4 in this task.
