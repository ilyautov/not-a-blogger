# Prepare visual assets

Read [AGENTS.md](../../../AGENTS.md) in the not-a-blogger checkout. Input: shot plan, chosen style, output sizes,
the person's own references and permission to use them. Keep the script and shot purpose intact.

Choose [real objects/photos](../../../recipes/image/image-real-object-real-photo.md) when they are the evidence.
Use generated material as an identified illustration, not fabricated source footage. For backgrounds use the
[preamble](../../../prompts/image/backdrop-preamble.md); use [image recipes](../../../recipes/image/README.md)
for inserts, loops or depth layers only when the shot needs them. Reuse available generation tools; if unavailable,
deliver prompts and missing setup as a proposal, not imaginary generated files.

Keep character identity/style consistent across the requested assets. Check actual dimensions, alpha, crop and
legibility in the target frame. Save source/prompt, generation tool/date, file identity, author/license and intended
use with the asset manifest. Follow [third-party terms](../../../docs/THIRD-PARTY.md) and
[brand boundaries](../../../docs/BRAND.md); the author's mascot is not the default character for everyone.

Output: actual asset paths and provenance, or explicitly unexecuted prompts, plus failed/missing items. Do not
alter the voice, add camera motion or render the whole video to complete an asset request.
