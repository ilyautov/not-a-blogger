# Скиллы для агента

[English](README.md) · [Тулкит](../../README.ru.md)

**15 узких скиллов + 3 скилла для всего процесса.** Выбирай нужную задачу. У каждого скилла свои входные данные,
результат и границы работы, затем ссылки на рецепты и инструменты. Это инструкции проекта, а не новые движки.
Держи их в этом клоне: скиллы ссылаются на его файлы.

## Сделать одну часть

## Собрать весь процесс

| Скилл | Вход → результат |
|---|---|
| [nab-video](nab-video/SKILL.md) | Вести сборку ролика, подключая только текущий этап |

| [nab-publisher-builder](nab-publisher-builder/SKILL.md) | Вести сборку отдельного публикатора из компонентов |

Задача только по субтитрам сохраняет голос и сцены; просмотр кадров не запускает пересборку; для очереди без сети
не нужен адаптер браузера. Общие скиллы выбирают нужные этапы, а не читают всё сразу. Инструкции по-английски,
с человеком агент общается на его языке. Существующие скиллы полного стартера
[reel-starter](../../starter/.agents/skills/reel-starter/SKILL.md),
[reels-direction](../../starter/.agents/skills/reels-direction/SKILL.md) и
[camera-moves](../../starter/.agents/skills/camera-moves/SKILL.md) остаются справочниками.

## Codex

Открой этот репозиторий как проект. Codex ищет `.agents/skills/` от рабочей папки до корня репозитория.
Выбери скилл через `/skills` или введи `$`. Если новые скиллы не появились, перезапусти Codex. Примеры:

```text
$nab-captions Сделай SRT/VTT по готовым таймингам. Сохрани голос и сцены.
$nab-qa-picture Посмотри кадры финального MP4, не пересобирай ролик.
$nab-publisher-queue Реализуй только очередь и разрешения без сети, с фейковым сервисом для тестов.
$nab-video Помоги собрать первый ролик. Есть Node 22 и ffmpeg, Python нет.
```

Загрузка скиллов: [официальная документация OpenAI](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills).
Глобальная установка и правка конфигурации для этих скиллов проекта не нужны.

## Claude Code

Локальные скиллы проекта лежат в `.claude/skills/`. Из корня этого репозитория скопируй недостающие папки:

```bash
mkdir -p .claude/skills
for skill_source in .agents/skills/nab-*; do
  skill_target=".claude/skills/${skill_source##*/}"
  if [ ! -e "$skill_target" ] && [ ! -L "$skill_target" ]; then
    cp -R "$skill_source" .claude/skills/
  fi
done
```

Существующие копии пропускаются, в том числе старые общие скиллы. После обновления тулкита проверь изменения
и осознанно обнови эти копии: автоматической синхронизации нет. Вызывай `/nab-captions`, `/nab-qa-picture` или другой
скилл по имени папки. [Документация локальных скиллов Claude Code](https://code.claude.com/docs/en/skills#choose-where-skills-load).
Копии проекта не подтверждают доступность скиллов в облачных сессиях Claude.

## Другие агенты и границы проверки

Попроси агента с доступом к файлам прочитать только выбранный `SKILL.md` и корневой `AGENTS.md`, затем работать
в этом клоне. Встроенный выбор скиллов и специальная система субагентов для такого способа не нужны.

Проверки формата/ссылок, копирования и независимые задания без внешних действий проверяют структуру, выбор скилла
и передачу результата. Они не доказывают появление скилла в меню, новый готовый ролик, художественное качество
или настоящую загрузку. Скиллы публикатора разбирают и собирают компоненты, не входят в аккаунты и не отправляют видео.
Публикацию запускает человек после просмотра точного файла. Границы частичного QA и одобрения сохраняются.
