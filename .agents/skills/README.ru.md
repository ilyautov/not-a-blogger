# Скиллы для агента

[English](README.md) · [Тулкит](../../README.ru.md)

Три входа от задачи к нужным рецептам и инструментам. Это инструкции агенту, а не новые движки рендера или сервис.
Держи их в этом клоне: скиллы ссылаются на файлы тулкита.

| Скилл | Когда нужен | Что отдаёт |
|---|---|---|
| [nab-video](nab-video/SKILL.md) | Сделать или переделать короткий ролик | Подходящий путь сборки, согласование сценария/постановки и отчёт о результате |
| [nab-video-qa](nab-video-qa/SKILL.md) | Проверить MP4 или отчёт QA | Проверки точного файла, замечания по кадрам и то, что осталось непроверенным |
| [nab-publisher-builder](nab-publisher-builder/SKILL.md) | Собрать своего публикатора | Отдельную реализацию или задание на неё, тесты восстановления и инструкцию проверки аккаунта |

В полном стартере уже есть [reel-starter](../../starter/.agents/skills/reel-starter/SKILL.md),
[reels-direction](../../starter/.agents/skills/reels-direction/SKILL.md) и
[camera-moves](../../starter/.agents/skills/camera-moves/SKILL.md). Новые входы используют их, а не заменяют
инструкции сборки. Три новых скилла написаны по-английски; с человеком агент общается на его языке.

## Codex

Открой этот репозиторий как проект. Codex ищет `.agents/skills/` от рабочей папки до корня репозитория.
Выбери скилл через `/skills` или введи `$`. Если новые скиллы не появились, перезапусти Codex. Примеры:

```text
$nab-video Помоги собрать первый ролик. Есть Node 22 и ffmpeg, Python и настройки голоса нет.
$nab-video-qa Проверь starter/output/final.mp4 и его отчёт QA. Что ещё не проверено?
$nab-publisher-builder Собери отдельный публикатор для моего YouTube. Начни с тестов восстановления без аккаунта.
```

Где загружаются скиллы: [официальная документация OpenAI](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills).
Глобальная установка и правка конфигурации для этих скиллов проекта не нужны.

## Claude Code

В локальном Claude Code скиллы проекта лежат в `.claude/skills/`. Из корня репозитория скопируй три папки,
если таких папок ещё нет. Существующую копию сначала проверь, не заменяй вслепую:

```bash
mkdir -p .claude/skills
cp -Rn .agents/skills/nab-video .claude/skills/
cp -Rn .agents/skills/nab-video-qa .claude/skills/
cp -Rn .agents/skills/nab-publisher-builder .claude/skills/
```

Вызывай `/nab-video`, `/nab-video-qa` или `/nab-publisher-builder`.
[Документация локальных скиллов Claude Code](https://code.claude.com/docs/en/skills#choose-where-skills-load).
Это копии для проекта; инструкция не подтверждает их доступность в облачных сессиях Claude.
После обновления тулкита обновляй копии осознанно, автоматической синхронизации нет.

## Другие агенты и границы проверки

Попроси агента с доступом к файлам прочитать выбранный `SKILL.md`, корневой `AGENTS.md` и выполнить задачу в этом клоне.
Так можно обойтись без встроенного выбора скиллов; это не означает нативную интеграцию со всеми агентами.

Проверка формата/ссылок и независимые сценарии без внешних действий проверяют структуру и поведение в отчёте.
Они не доказывают появление скилла в меню клиента, новый готовый ролик, настоящую загрузку или художественное качество.
Скилл сборки публикатора не входит в аккаунты и ничего не публикует. Человек проверяет точный файл и запускает публикацию.
