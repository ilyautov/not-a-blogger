# QA thresholds

One table for every number a check in this repo fails on. Recipes, the textbook and the starter quote these values
and link here instead of carrying their own copies. When you change a threshold, change it here first, then in the
"Enforced in" file, then in the recipes listed in the last column.

**Status** says where the number comes from:

- *measured*: the value was chosen after measuring real takes or published videos; the sample is named;
- *chosen*: a working default nobody has measured against an outcome yet. Treat it as a hypothesis;
- *floor*: the check fails below it, but passing it proves nothing by itself; the real criterion is in the recipe.

All loudness numbers are measured on the encoded mp4 (`ffmpeg -af ebur128=peak=true`), never on the master: AAC
lifts peaks by 1–2 dB on plosives (`tools/audio/aac_safe.py`, `templates/skit/README.md`).

## How to change a value

1. Measure first: at least a handful of takes or one published video, with the command that produced the number.
2. Edit this table (value, status, sample) and the "Enforced in" file in the same change; `grep -rn` the old number
   across `recipes/`, `learn/`, `starter/` and fix every copy.
3. Recipes keep only the agreed value and a link here; the measurement goes into the recipe's Evidence.
