# slides: HTML-дек одним файлом и генератор из Markdown

- `deck.html`: шаблон. Один файл без фреймворков и сети: слайды `section.slide`, навигация стрелками, пробелом,
  PageUp/PageDown, Home/End и кликом, номер «N / M», полоса прогресса, `#5` в адресе открывает пятый слайд. Размеры
  используют `clamp()` с нижней границей: на узком экране основной текст не меньше 16 px, кнопки не меньше 44×44 px.
  Длинный слайд прокручивается над отдельной нижней областью навигации; код и широкие таблицы можно листать горизонтально.
- `md2deck.py`: Markdown → готовый дек на этом шаблоне. Слайды разделяются строкой `---`.
- `themes/*.css`: токены цвета и шрифтов (`paper`, `night`), подставляются в `<style id="theme">`.

## Команда

```bash
cd tools/slides
python3 md2deck.py examples/coffee-turka.md -o out/coffee.html
python3 md2deck.py examples/coffee-turka.md -o out/coffee-night.html --theme themes/night.css
open out/coffee.html            # Linux: xdg-open
```

Зависимостей нет. С пакетом `markdown` (`pip install -r requirements.txt`) работают таблицы и вложенные списки, без
него встроенный разбор понимает заголовки, абзацы, списки, цитаты, блоки кода, `**жирный**`, `*акцент*`, ссылки.

## Формат Markdown

```markdown
---
title: Как сварить кофе в турке
theme: themes/night.css
---

<!-- class: center -->
::: kicker Кофе дома
# Кофе в турке
Три минуты, четыре шага и одна ошибка.

---

## Пропорции
- **10 г** кофе на **100 мл** воды
```

- `---` внутри блока кода (```` ``` ```` или `~~~` любой длины) слайд не режет; блок закрывает только такая же ограда
  не короче открывающей, так что в блоке из четырёх обратных кавычек можно показать вложенный ```` ``` ````.
- `<!-- class: … -->` и `::: kicker` внутри блока кода остаются текстом примера, а не директивой.
- `<!-- class: center -->` добавляет класс слайду (`center` центрирует).
- `::: kicker Текст` даёт надзаголовок.
- `*акцент*` красится цветом акцента: одно слово на слайд.

## PDF

Открой дек в Chrome или Firefox, Ctrl/Cmd+P, «Сохранить как PDF», поля «Нет», включи «Фон». Печатный CSS
(`@media print`) ставит каждый слайд отдельной страницей 1280×720 и прячет навигацию. Проверь `pdfinfo deck.pdf`:
страниц столько же, сколько слайдов, размер 960×540 pt.
Мобильная прокрутка не меняет печатный размер. Длинное содержимое для печати всё равно дели на несколько слайдов:
фиксированная страница 16:9 не вместит произвольный объём текста.

На длинном мобильном слайде вертикальные клавиши и пробел сначала прокручивают текст; стрелки влево/вправо
и нижние кнопки всегда меняют слайд. Tab переводит фокус на кнопки и прокручиваемые блоки.

## Грабли

- **Дек без фреймворка агент правит целиком.** Один HTML читается и меняется за один проход; reveal.js и подобные
  тянут сборку и CDN, на выступлении без сети они ломаются.
- **PDF-копия на случай чужого компьютера.** Распечатай PDF заранее (`recipes/slides/slides-html-deck-with-pdf-backup.md`),
  проверь число страниц (`recipes/slides/slides-check-pdf.md`).
- **Фон пропадает при печати**, если не включить «Фон» в диалоге; в шаблоне стоит `print-color-adjust: exact`, но
  браузер может переопределить (`recipes/slides/slides-print-css.md`).
- **Длинное тире и «не просто X, а Y»** на слайде палят машинный текст так же, как в карточках. Прогони текст через
  гейты `tools/carousels/cards.py` или через хуманайзер до сборки.
- **Шрифты по имени**: Inter / Noto Sans / PT Serif (OFL) должны стоять на машине, где показываешь, иначе браузер возьмёт
  системный. Скачать: https://rsms.me/inter/, https://fonts.google.com/noto, https://fonts.google.com/specimen/PT+Serif.
- **QR на последнем слайде** вставляй картинкой base64 прямо в HTML, чтобы дек остался одним файлом.
