# Среда, сеть и место

Вход: ваш компьютер и папка starter. Дата профиля — 23.10.2026.
Это проверенный пример машины, а не заявленные минимальные требования.

| Компонент | Проверено в локальном протоколе | Граница |
|---|---|---|
| Машина | macOS 26.2, Apple M1 Max, 64 ГБ RAM | Минимум RAM и диска не измерен; другая машина требует пробного прогона |
| Базовый стек | Python 3.11.7, Node 24.21.0, ffmpeg/ffprobe 8.1.1 | Doctor требует Python 3.11 и Node ≥18; lock-файлы рассчитаны на macOS arm64 |
| Python | Новый venv пайплайна и отдельный venv OmniVoice, pip check | Другие версии зависимостей не объявлены проверенными |
| Рендер | TypeScript, Canvas 2D, локальный Chromium | Для этого пути NVIDIA и модель LTX не нужны |
| OmniVoice | CPU и MPS на этом Mac | CUDA не проверен; время CPU не является оценкой GPU |
| Другие ОС | Linux не проверен; Windows не поддержан из-за fcntl | Инструкции не обещают универсальный установщик |

Протокол проверки автора (точные MP4, SHA256, измеренные этапы) в starter не входит; текущее состояние вашей машины проверяет `./make.sh doctor`.
Успешный doctor не доказывает наличие весов Whisper/OmniVoice и не заменяет сборку.

## Где нужна сеть

| Действие | Что загружается | После установки |
|---|---|---|
| `npm ci` | TypeScript по package-lock.json из npm | Компилятор локально в node_modules |
| pip по requirements-lock | Python-пакеты из индекса | Пакеты в выбранном venv |
| `python -m playwright install chromium` | Версия Chromium для Playwright | Браузер в системном кэше Playwright |
| `./make.sh fonts` | Onest/PT Serif и лицензии | Файлы в assets/fonts |
| Первый `live`/`voice` trim и финальный ASR | Whisper, по умолчанию large-v3, из Hugging Face | Используется локальный кэш, пока он доступен |
| Опциональный OmniVoice | Пакеты, выбранные веса и зависимости модели | Локальная модель по OMNI_MODEL |

Модели и кэш не входят в starter и checkpoint. Сетевое скачивание всех весов с нуля на новой машине
в протоколе не повторяли: Chromium, Whisper и OmniVoice были использованы из существующего кэша/хранилища.
Не называйте это проверкой полностью офлайн-установки. `fake` и `--no-asr` позволяют проверить сборку без моделей,
после установки пакетов, браузера и шрифтов. Их результат остаётся `preview_partial`.

## Перед длинным запуском

```sh
./make.sh doctor
df -h .
du -sh .venv node_modules assets output qa .checkpoints 2>/dev/null || true
```

Выход: проверки среды и фактическое свободное место/размер существующих папок. Отсутствующая папка до первого запуска допустима.
Оцените место для зависимостей, весов, покадрового рендера, WAV, MP4 и нескольких контрольных копий.
Restore одновременно хранит архив, проверенные распакованные файлы и страховочный архив.
Автоматической очистки старых копий нет. Сначала испытайте короткий fake-прогон; он покажет ваш расход диска и время.
Если места не хватает, выберите данные для удаления сами. Не удаляйте текущий финал и единственный приватный голосовой референс.

Готовые модели и личный голос имеют собственные условия использования. [THIRD-PARTY.md](THIRD-PARTY.md)
разделяет лицензию кода и весов. Измеренный LUFS не подтверждает естественность синтеза.
