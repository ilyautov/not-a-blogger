## When
The CTA worked, people write "send it", but the material doesn't exist or nobody knows where to get it. Demand comes and goes, and the next CTA earns less trust.

## Do
Before publishing check three things:
1. The material exists and opens by link (page, file, post).
2. The link sits where a person from this platform can tap it: description or pinned comment on long videos; profile link or Related Video on YouTube Shorts, where description and comment URLs are not clickable ([YouTube Shorts link](cta-youtube-link-in-description.md)).
3. Someone is assigned to answer comments in the first hour.

```text
[ ] material ready: <link>
[ ] link in description / pinned / profile
[ ] first-hour comment replies: <who>
```

## Verify
Every request comment gets a link the same day.

## Don't
- Don't post an empty CTA: if nobody but you needs the material yet, skip the CTA.

## Evidence
A LinkedIn post with 19.5k impressions: three people publicly asked for the guide in comments and nobody told them where to get it; no clickable channel link, only a mention in the profile headline. Over the same period more than 13k impressions gave 0 link clicks.
Platform metrics of one published post (19.5k impressions, 3 public requests, 0 link clicks over 13k impressions); dated 2026-10.
