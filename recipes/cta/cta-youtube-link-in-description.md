## When
"Comment the word, I'll DM you" lives on Instagram. YouTube has no DMs, so the same video with the same ending leaves viewers without the material. A URL pasted into a Shorts description or comment does not help either: YouTube makes ordinary links in Shorts descriptions and comments unclickable ([YouTube Help](https://support.google.com/youtube/answer/13748639?hl=en)).

## Do
1. For a YouTube Short change the ending or caption: "link in the profile" (or "full video below") instead of "comment the word".
2. External material (a page, a guide): put its link in the channel profile links (channel About / header links) and point the Short there.
3. Your own long video on the same topic: attach it to the Short as the **Related Video** in YouTube Studio; that link appears on the Short and is clickable.
4. Long (non-Shorts) videos: a link in the first description line and in a pinned comment is fine there; it stays clickable.
5. One video for all platforms: the on-screen codeword may stay, but on YouTube the path to the material is the profile link or the Related Video.

## Verify
Open the Short logged out on a phone and on desktop and actually tap through: the profile link or the Related Video opens the material. Seeing the URL text in the description does not count.

## Don't
- Don't use a description URL or a pinned comment as the route out of a Short: both are plain text on Shorts.
- Don't rely on a codeword on YouTube: there are no DMs to answer it.

## Evidence
No own click measurement. The unclickable-links rule comes from YouTube's own help page (link above), cited in a 29 Oct 2026 review; the earlier version of this recipe recommended a pinned comment as backup, which that page rules out.
