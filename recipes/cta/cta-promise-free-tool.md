## When
A codeword alone doesn't work: if behind it is "a set of tips" or "useful material", viewers have no reason to comment.

## Do
Promise something usable right away:
- link to an open tool (repo) + step-by-step install guide;
- a free lesson with a concrete result;
- a cheat sheet for exactly what the video shows (all shortcuts, all commands).

Formula: "Comment <word>, I'll send <tool link> and <how to install it in N minutes>".

## Verify
Under the video the word appears more often than "what's in it?" questions.

## Don't
- Don't promise a tool that takes long to set up without a guide to the first result: comments come, disappointment follows.

## Evidence
Sample of 1,470 AI reels: most comments went to "link to an open-source agent on GitHub + full install guide" (9,207 comments at 190k views) and "free lesson + agent link" (9,138 at 94k). A business lesson without a tool got 30–330 comments.
