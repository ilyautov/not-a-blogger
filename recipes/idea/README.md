# Idea and script

Where topics come from and how to check a script before building. Recipes follow the [template](../../templates/recipe.md).

| Recipe | Status | Lang | Gist |
|---|---|---|---|
| [Build around an everyday situation or genre parody, not the tool](idea-everyday-absurd.md) | proven | any | "Asked the AI to do X → absurd" and genre worlds beat tutorials. |
| [Keep a fact-check file and dropped-claims list per video](idea-factcheck-file.md) | proven | any | `qa/factcheck.md` per video; verify commands against the installed CLI. |
| [Take ideas from niche hits selected by author median](idea-find-hits-by-median.md) | proven | any | Hit = ≥5× author median and ≥100k; every idea cites a reference with numbers. |
| [Five timed beats, timestamped hero](idea-five-beat-skeleton.md) | hypothesis | any | Hook at 0.0 → mistake → numbers → steps → twist + keyword, ≤45 s; measure your own words/s. |
| [Guessing game or exposé first, how-to as the tail](idea-guess-over-howto.md) | proven | any | Guessing game median 3.7k vs 787 for how-to. |
| [No sequel on the same template](idea-no-repeat-own-hit.md) | proven | any | Copying a winning template = slop; back-to-back second version got 3 views. |
| [Reel under 40 s, one example, punchline first](idea-one-example-short-reel.md) | hypothesis | any | ≤40 s, one example, punchline up front, methodology to the caption; runtime ≈ N/4 lines. |
| [Remake a fresh proven hit second by second, rebuilt with your own means](idea-remake-rhythm-not-words.md) | hypothesis | any | Transfer the skeleton of a fresh niche hit (roles, order, line lengths, cuts, pauses, hook template); own lines on own material, no translating; no shared run >2 words. |
| [Show a 3–5 line script and knowledge chain before building](idea-script-before-build.md) | proven | any | Script, first frame, knowledge chain before voice and render; no skeleton repeated in 3 videos. |
| [Break down the reference before a remake](idea-breakdown-reference-before-remake.md) | hypothesis | any | `breakdown.py --compare`: reference drifted inside every shot (fast 0.76), remake stood still (0.09); fix drift, not cuts. |
| [Answer a funny comment with the next video](idea-answer-comment-video.md) | hypothesis | any | Top extending question from a spiking video's comments → short answer video in the same grammar. |
| [Treat a borrowed format as perishable, take it within days and keep only the structure](idea-format-lifecycle-week.md) | hypothesis | any | Reference < ~3 days and no copies: build now; copies out: structure only, own situation; no same-storyline sequels. |
| [Open with an archival photo and a riddle question about the history of a technology](idea-history-riddle.md) | hypothesis | any | Archival photo + riddle in the first 0.2 s, one object per frame, answer at the end, loop to the start. |
| [Pick a topic a person outside your niche cares about, and let AI be the twist](idea-topic-wider-than-niche.md) | hypothesis | any | Everyday pain or story first, AI as the twist; topic must make sense to a non-specialist in one sentence. |
